# 教师 tags 信息量消融与双管线决定（ml-ranking）

**Created:** 2026-08-16
**Branch:** `feat/ml-ranking`（脚本 `scripts/ml_tags_ablation_probe.py`）
**问题:** `topic_group` / `style_key` / `temporal_class` 是教师输出，被
spec S1.2 禁作输入特征（标签泄漏）。两条恢复路径：

- **A（双管线）**：廉价 tags-only LLM 通道全量打标，真 tags 作特征；
- **B（元蒸馏）**：辅助头从历史标签自预测 tags 作特征。

**判定规则（事前约定）**：v1（oracle tags）与 v2（基线）的 Δρ——
Δρ < 0.02 选 B；Δρ > 0.05 说明 tags 是主信号，付 A 的成本。

## 数据与协议

- 686 行未截断教师标签（S0.3a 溯源口径：599 非零 + 87 audit 恢复），
  平台 tags 字段实测全空（`tags`/`raw_payload` 0/578），
  "tags" 即教师结构化标注（style 12 类 / temporal 5 类 / topic top-15）。
- StratifiedKFold(5)×3 seeds（分层：平台×style），Ridge（ρ）+
  Logistic（AUC，y 按行取 effective_admission_threshold）。
- v1 的同调用泄漏是**故意的**：它模拟的正是 A 采购到的信息。

## 结果

| 配置 | 维度 | ρ | ρ bilibili | ρ xhs | AUC |
| --- | --- | --- | --- | --- | --- |
| v1 oracle（含 tags） | 75 | 0.715±0.037 | 0.672 | 0.664 | 0.864±0.022 |
| v2 基线 | 41 | 0.604±0.045 | 0.551 | 0.454 | 0.799±0.028 |
| **Δ** | | **+0.111** | +0.121 | **+0.210** | +0.065 |

## 决定：Δρ > 0.05 → 选 A（双管线）

1. **B 不是便宜一点的 A**：多任务原型的 B 已实现值 ρ = 0.616 vs 基线
   0.612，只拿到 tags 信息增量的约 4%（辅助头预测准确率 style 0.39 /
   temporal 0.50，远低于真值可用性）。
2. **A 的管线形态**（与 S1.8 衔接）：廉价 tags-only 通道（无画像块、
   无批 rubric、只输出 3 字段）→ ML 准入判定 → 仅 y=1 走完整 LLM 评估
   （完整评估自产 tags 覆盖廉价版）。成本项 = 廉价通道的单条价格 ×
   全量候选，**需单独实测后更新 S1.8 的成本模型与 ≤70% 验收线**。
3. **附带发现**：xhs ρ 从 0.454 → 0.664（+0.21）几乎追平 bilibili
   ——xhs 之前的弱不是平台属性，是缺标注语义（它无时长/播放量）。
   AUC 口径 v1 0.864 过 S1.5 的 0.80 门槛，v2 0.799 压线
   （profile_digest 分组切分下仅 0.724）——tags 也是二分类门槛的
   关键缺口。
4. **口径说明**：Δρ 中有一部分是"教师分数与自身标注的自洽性"而非
   纯内容信号；但对 A 的决策问题（付钱换回多少准入复现精度）这
   正是要测的量。

## 局限

n=686、单用户；廉价通道的真实成本与质量未实测（下一步）；
v1 的 topic one-hot（top-15/224 类）在更多数据下类目会膨胀，
需改 embedding 化（topic 向量而非 one-hot）。
